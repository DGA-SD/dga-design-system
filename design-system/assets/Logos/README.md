# Logos

`dga-logo.webp` is the official DGA logo (339×194 WebP, transparent), taken unchanged from dga.or.th. It combines an orange "DG" with circuit ends (#F05123, matching `orange`), a navy "A" (#1C164B, matching `navy`) and the wordmark "DIGITAL GOVERNMENT DEVELOPMENT AGENCY" in orange and navy.

- Place it on white (`surface`, light theme) directly.
- On `navy`, dark theme, photographs or orange, put it on a white plate (`on-navy` fill, `space-2`–`space-4` padding, `radius-sm`/`radius-md`). The components do this automatically.
- Minimum height is 48px on screen and 56px on 1920×1080 slides. Keep clear space equal to the height of the "A".
- Never recolour, redraw or stretch it. For print, or a reversed/white version, request vector files from DGA Corporate Communications; this system holds only the web raster.
