# SlideContent

The workhorse content slide has a kicker, a title that states the takeaway, 3–5 bullets and an optional big number or chart on the right, with a footer line and the logo at bottom-right.

**Consumer provides:** a kicker (topic), a title written as the conclusion rather than the topic, up to five bullets of about 12 words each, and optionally one stat or one chart using `chart-1`/`chart-2`.

- Type: `slide-title` 48px, `slide-body` 26px (never below 24px), and `slide-stat` 120px in `orange`.
- Margins are `space-24`. One orange accent per slide: either the stat or the highlighted chart series.
- In the dark theme the same markup inverts. Put the logo on a plate (`dga-slide__plate`).
