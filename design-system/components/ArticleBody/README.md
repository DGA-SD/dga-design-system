# ArticleBody

`.dga-prose` is the long-form reading layout for articles, blog posts and news bodies: one 680px column, Sarabun body text and Prompt headings.

**Consumer provides:** semantic HTML (`h1`, `.byline`, `.lead`, `h2`/`h3`, `p`, lists, `figure` with `figcaption`, and `blockquote.dga-quote`) inside `<article class="dga-prose">`.

- Body is `article-body` (Sarabun 18/32) in `ink-secondary`; headings are Prompt in `ink`; list markers are orange.
- Start with a badge, title, byline (author · Buddhist Era date · reading time) and a one-sentence `.lead`.
- Keep paragraphs to four lines or fewer on desktop, and use `h2` about every 3–5 paragraphs.
- Don't justify Thai text, and don't set body text in Prompt at article length.
