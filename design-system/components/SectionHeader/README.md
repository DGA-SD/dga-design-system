# SectionHeader

This is the home-page section heading from dga.or.th: an optional small navy kicker, a 32px orange title and a "ดูทั้งหมด" link on the right.

**Consumer provides:** the title text (one line), an optional kicker and an optional link.

- The title is `section-title` (32/32, 600, `orange`), which passes contrast only because it is large.
- If the title can wrap (on mobile or with long Thai), add `dga-section-header--wrap` to use a 44px line height so Thai upper vowels don't clip.
- Use one per page section, not inside cards.
