# Callout

A callout sets a key fact or summary box inside an article. The pull quote (`dga-quote`) is its sibling.

**Consumer provides:** a short title ("สาระสำคัญ", "ข้อควรรู้") and 1–3 sentences. For a quote, the quoted line and a `<cite>`.

- `dga-callout` uses an `orange-soft` fill. `dga-callout--navy` is for product spotlights, with an orange title on navy (4.69:1).
- Use one callout per screenful. Pull quotes are real quotes with attribution, never invented.
- This is not a left-border box; the quote's short orange rule sits above the text.
