# Badge

A badge is a small pill label for a content category (ข่าว, บทความ, มาตรฐาน) or the status of a project.

**Consumer provides:** a `<span class="dga-badge">` with 1–3 words, plus a modifier: none for an `orange-soft` category, `--navy` for a formal type, or `--success` / `--warning` / `--danger` / `--info` for status.

- Every status badge carries a word, and preferably a leading glyph or icon; colour alone never carries the meaning.
- Use one badge per card. Don't stack badges or use them as buttons.
